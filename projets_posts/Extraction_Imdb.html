--- title: Projet2 --- Extraction IMDb Top 250

Extraction des 250 meilleurs films IMDb

1. Introduction / Objectif

Dans ce projet, l’objectif est d’extraire les informations relatives aux 250 films les mieux notés sur IMDb à l’aide de Python et de bibliothèques spécialisées en web scraping.

Cette extraction est réalisée dans un cadre éducatif et dans le respect des conditions d’utilisation d’IMDb.

Note : Les données utilisées proviennent d’IMDb et ont été exploitées exclusivement à des fins éducatives. Le script complet n’est pas publié afin de respecter les conditions d’utilisation.

Pour accéder à la version complète du script, vous pouvez me contacter.

2. Environnement et bibliothèques utilisées

  • Requests : pour envoyer des requêtes HTTP et récupérer le contenu des pages web.
  • BeautifulSoup (bs4) : pour parser le code HTML et extraire les données.
  • Pandas : pour organiser, structurer et manipuler les données extraites.

3. Envoi de la requête HTTP

La première étape consiste à envoyer une requête vers l’URL du classement IMDb Top 250.

IMDb bloque les requêtes automatiques sans User-Agent et renvoie une erreur 403. La solution consiste à ajouter un en-tête User-Agent afin de simuler un navigateur réel.

4. Navigation dans le HTML

Avant d’extraire les données, il est essentiel d’inspecter la structure HTML de la page.

En ouvrant la page IMDb Top 250 Films dans un navigateur et en utilisant l’outil Inspecter, on identifie les balises et classes CSS contenant les informations recherchées (titres, notes, liens…).

5. Extraction avec BeautifulSoup

Nous avons utilisé la méthode select() avec des sélecteurs CSS pour cibler les éléments pertinents, et find_next() pour récupérer les balises voisines comme l’année ou la note.

  • soup.select("li a[href^='/title/']") → cible tous les films de la liste.
  • item.find_next("span") → récupère l’année ou d’autres informations situées juste après le titre.
  • item.find_next("span", class_="ipc-rating-star__rating") → extrait la note IMDb.

Le script complet n’est pas publié afin de respecter les conditions d’utilisation d’IMDb. Seule une version simplifiée est présentée pour illustrer la méthodologie.

6. Structuration des données

Les données extraites sont stockées dans un DataFrame Pandas pour faciliter la manipulation et la vérification de leur qualité.

📌 Points clés à retenir

  • Classement IMDb (Rank) : correspond à la position officielle d’un film dans le Top 250. Exemple : Rank 1 → The Shawshank Redemption, Rank 2 → The Godfather, Rank 3 → The Dark Knight.
  • Importance de l’encodage UTF-8 : garantit la conservation correcte de tous les caractères spéciaux et symboles non latins dans le CSV (ex. Alejandro González Iñárritu).
  • Chargement partiel des films : IMDb ne place pas les 250 films dans une seule page statique. Requests + BeautifulSoup récupèrent seulement les films présents dans le HTML initial (souvent 25 premiers films). Pour récupérer tous les films, il faut combiner parsing HTML + JSON généré dynamiquement.
  • Réalité du web scraping : la structure HTML d’IMDb change régulièrement. Un script fonctionnel aujourd’hui peut cesser de fonctionner demain.
